## Как обновляются встроенные расширения

`.ruru-bundle.properties` хранит хеши файлов, которыми управляет приложение. Перед заменой проверяются все прежние управляемые исходники. Любое пользовательское изменение, неизвестный старый пакет, небезопасная ссылка или конфликт нового исходника с пользовательским файлом приводит к `PreservedLocalChanges`: приложение не затирает такой пакет. Событие `bundled_extension_sync` фиксирует результат в диагностике.

Базовые хеши в `app/src/main/assets/ruru-extension-baselines/` сгенерированы из точного коммита базы, а не из новой версии. `node_modules` сохраняется при замене; необходимость обновления зависимостей отдельно определяет dependency fingerprint. Маркеры ранее удалённых встроенных пакетов продолжают действовать. Сброс Alpine для применения исправлений не требуется.

Старые пользовательски изменённые или неполные пакеты не чинятся принудительным перезаписыванием. Это осознанная граница безопасности, а не гарантия автоматической миграции любой произвольной установки.

## Не объявлено исправленным

- R06: общая очередь extension runtime ещё может ждать зависший сторонний handler. Безопасная отмена требует отдельного дизайна владения состоянием; простое Promise.race не останавливает старый обработчик.
- R08: неограниченная очередь событий Android bridge; нужен отдельный механизм ограничения без потери tool/response-событий и без взаимной блокировки host callbacks.
- R09: добавлены регрессионные тесты реальных исходников, но полный отдельный typecheck каждого bundled-пакета ещё не введён.
- R10: локальные копии AetherExtensionAPI во встроенных расширениях пока не заменены общим контрактом.
- R11: общий и Android-пути удаления имеют различия; Android уже вызывает reload, поэтому ложный диагноз «reload отсутствует везде» не реализован. Поля отложенного применения изменений требуют отдельной унификации.

Также не заявлены замеры батареи/памяти, полноценная проверка сетевых провайдеров, iOS-сборка или стопроцентная проверка всех сторонних расширений.
